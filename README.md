Geminin vibellystä. Tähän ei eläin pysty.

Firefoxissa pitää olla google-oikeudet tietty:

mkdir -p ~/.mozilla/selenium-profiili 

firefox -profile ~/.mozilla/selenium-profiili -no-remote https://play.google.com/books &

Varmistus: Kansion ~/.mozilla/selenium-profiili sisälle on ilmestynyt cookies.sqlite ja muita profiilitiedostoja.
